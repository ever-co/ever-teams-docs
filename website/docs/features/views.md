# Choosing a View

Ever Teams shows the same work in several ways. This page helps you pick the view that fits what you are doing, and links to the page that documents each one in detail.

## At a glance

| View                                 | Where                      | Best for                                              | Details                                |
| ------------------------------------ | -------------------------- | ----------------------------------------------------- | -------------------------------------- |
| **List** (default task view)         | Task list                  | Scanning many tasks, detailed data, bulk operations   | [Task Management](./task-management.md) |
| **Kanban board**                     | `/kanban`                  | Visual workflow management, moving work between stages | [Kanban Board](./kanban.md)            |
| **Calendar**                         | `/calendar`                | Deadline-driven planning, rescheduling due dates      | [Calendar View](./calendar.md)         |
| **Team view**                        | Main team page             | Seeing who is working on what right now               | [Teams & Organizations](./teams.md)    |
| **Project list and project detail**  | Projects page              | Work, members, time and budget scoped to one project  | [Projects](./projects.md)              |
| **Daily plan**                       | Team view or Dashboard     | Choosing what you will work on today                  | [Daily Plans](./daily-plans.md)        |

## Pick a view by goal

- **"What is everyone working on right now?"** Open the team view. It lists each member with their current task, timer status and activity.
- **"Where does each task stand in our workflow?"** Open the [Kanban board](./kanban.md). Columns come from your task statuses, so moving a card changes its status.
- **"What is due, and when?"** Open the [Calendar](./calendar.md). Tasks appear on their due dates, and dragging a task to another date changes its due date.
- **"I need to review or filter a lot of tasks at once."** Use the task list. It shows status, title, assignees, priority, size, timer, due date and tags in one row per task.
- **"How is one project doing?"** Open the project from the [Projects](./projects.md) page to see its tasks, members, time summary and budget use.
- **"What will I do today?"** Use a [daily plan](./daily-plans.md).

## What the views have in common

- **Same tasks, different layout.** Each view is a way of looking at tasks; a status, assignee or due-date change you make in one view is a change to the task itself.
- **Filtering.** The kanban board shares the list view's filters. The calendar offers filters by team member, project, priority and status. See [Task Filtering](./task-management.md#task-filtering) for the list-view filters.
- **Timers.** Cards on the kanban board and rows in the list carry a timer button, so you can start tracking without opening the task. See [Time Tracking & Timer](./time-tracking.md).

## Customizing what you see

- **Kanban columns** are generated from your task statuses. To add, rename, reorder or remove them, go to Settings → Task Statuses. See [Kanban Board](./kanban.md#columns).
- **Kanban swimlanes** group the board by assignee, priority or project. See [Kanban Board](./kanban.md#swimlanes).
