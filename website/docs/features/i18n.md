# Internationalization (i18n)

The Ever Teams web app is translated into 13 languages with [`next-intl`](https://next-intl-docs.vercel.app/). The mobile app has the same 13 and Korean.

## Supported Languages

| Code | Language   | Right to left |
| ---- | ---------- | ------------- |
| `en` | English    | No      |
| `fr` | French     | No      |
| `ar` | Arabic     | **Yes** |
| `bg` | Bulgarian  | No      |
| `zh` | Chinese    | No      |
| `nl` | Dutch      | No      |
| `de` | German     | No      |
| `he` | Hebrew     | **Yes** |
| `it` | Italian    | No      |
| `pl` | Polish     | No      |
| `pt` | Portuguese | No      |
| `ru` | Russian    | No      |
| `es` | Spanish    | No      |

:::note
On the web, Arabic and Hebrew are translated, but pages are still laid out left to right. The mobile app lays them out right to left, after a restart of the app when the direction changes.
:::

## How It Works

### Routing

Every page lives under a `[locale]` segment in the code (`apps/web/app/[locale]/`). In the address bar, English, the default language, has no prefix, and every other language has its code first:

```
/settings           → English
/fr/settings        → French
/ar/settings        → Arabic
```

### Translation Files

Translation files are JSON files stored in `apps/web/locales/`:

```
locales/
├── en.json      # English translations
├── fr.json      # French translations
├── ar.json      # Arabic translations
├── bg.json      # Bulgarian translations
├── zh.json      # Chinese translations
├── de.json      # German translations
└── ...          # Other locales
```

### Usage in Components

```typescript
import { useTranslations } from 'next-intl';

function TaskList() {
  const t = useTranslations('tasks');
  return <h1>{t('title')}</h1>;
}
```

### Adding a New Language

1. Create a new JSON file in `apps/web/locales/` (e.g., `ja.json`) with every key of `en.json`, translated
2. Add the locale code to `APPLICATION_LANGUAGES_CODE` in `apps/web/core/constants/config/constants.tsx`
3. Run the web tests: several of them check that every language holds the same keys as English

A new string follows the same rule the other way round: it is added to all 13 files in the same change, never to English alone.

### Crowdin Integration

Translation management is handled via [Crowdin](https://ever.crowdin.com/ever-teams), enabling community contributions:

- Source strings are extracted from the English locale
- Translators work on Crowdin's web interface
- Translated strings are synced back to the repo

## Mobile App i18n

The mobile app (`apps/mobile`) has 14 languages: the web's 13 and Korean (`ko`). Its translation files are in `apps/mobile/locales/`, one JSON file per language, and the code that loads them is in `apps/mobile/app/i18n/`.

## Desktop App i18n

The desktop server app (`apps/server-web`) has its own translation files, in `apps/server-web/src/locales/i18n/` (English and Bulgarian).
